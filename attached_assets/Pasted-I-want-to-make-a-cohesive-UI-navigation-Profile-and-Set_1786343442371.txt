I want to make a cohesive UI, navigation, Profile, and Settings improvement pass for Cubical.

The goal is to make Cubical feel softer, more inviting, and more personal while remaining clean and professional.

IMPORTANT:
- Do not redesign or break the existing Home widget system.
- Preserve draggable/resizable widgets and their saved layouts.
- Preserve Calendar events and Notepad data.
- Do not modify existing tool functionality.
- Preserve Store and Library functionality.
- Do not add accounts, payments, cloud sync, achievements, games, or company features in this pass.
- Keep all current persistent local data working.

--------------------------------------------------
1. SIDEBAR AUTO-COLLAPSE
--------------------------------------------------

Improve the existing left sidebar.

When expanded, it should continue displaying icons and navigation labels.

After approximately 4 seconds of inactivity:
- Automatically collapse the sidebar so only the navigation icons remain.
- Only collapse when the mouse is NOT hovering over the sidebar.
- Do not collapse while the user is actively interacting with sidebar controls.
- Moving the mouse over the collapsed sidebar should smoothly expand it again.
- After the mouse leaves and the inactivity delay passes, smoothly collapse it again.

The animation should feel polished and fluid.

Do NOT make the sidebar suddenly snap between states.

Add a small pin/unpin control.

When pinned:
- Sidebar remains expanded indefinitely.
- It should not automatically collapse.

When unpinned:
- Normal auto-collapse behavior returns.

Remember the user's pin preference locally after refresh/reopening Cubical.

Make sure collapsed icons have tooltips so users can identify navigation items without expanding the sidebar.

The collapsed sidebar should remain wide enough that icons are comfortable to click.

--------------------------------------------------
2. REMOVE BREAK TIMER
--------------------------------------------------

Remove the standalone Break Timer from Cubical.

Break timing/game limitations will eventually be handled through the Breakroom system instead.

Do not replace the Break Timer with another feature.

4. EXPAND PROFILE
--------------------------------------------------

Turn Profile into a more complete personal identity/customization page.

Profile should represent:

"Who I am and what my Cubical looks like."

Do NOT turn Profile into a general application settings page.

Add:

PROFILE IDENTITY

- Profile picture

Design the banner/profile area somewhat like a modern user profile:

Keep it professional and clean rather than making it look like a social media feed.

Persist profile information locally for the prototype.

--------------------------------------------------

Below the identity section, add a customization/appearance area specifically for Cubical skins.

This is where users will eventually see skins they own and choose which one is equipped.

For this prototype:

- Show "Default" as an owned skin.
- Create the architecture/UI for additional owned skins.
- Allow an owned skin to be selected/equipped.
- Clearly indicate which skin is currently equipped.
- Do not build a Store purchasing system for skins yet.
- Do not create a complicated inventory system yet.

You may add a disabled or placeholder Sakura skin entry if useful for demonstrating the future system, but do not attempt to build the Sakura environment itself in this pass.

The goal is to establish where owned Cubical skins will eventually live.

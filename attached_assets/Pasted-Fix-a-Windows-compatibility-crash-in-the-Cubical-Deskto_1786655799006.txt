Fix a Windows compatibility crash in the **Cubical Desktop Electron application**.

A clean install of Cubical 0.2.7 on another Windows PC installs successfully, but Cubical crashes during startup.

Running Cubical with Electron logging produced repeated errors:

`GPU process exited unexpectedly: exit_code=-2147483645`

followed by:

`FATAL:content\browser\gpu\gpu_data_manager_impl_private.cc:416] GPU process isn't usable. Goodbye.`

Windows Reliability Monitor reports:

* Application: `Cubical.exe`
* Version: `0.2.7.0`
* Problem Event: `APPCRASH`
* Exception Code: `80000003`
* Fault Module: `Cubical.exe`

## Targeted fix

In the Electron main process, add:

`app.disableHardwareAcceleration();`

It MUST execute at the earliest valid point in Electron startup:

* after Electron's `app` object is imported/available,
* BEFORE `app.whenReady()`,
* BEFORE any `BrowserWindow` is created.

The purpose is to force Cubical to use software rendering instead of Chromium's GPU acceleration path, which is crashing on the affected Windows machine.

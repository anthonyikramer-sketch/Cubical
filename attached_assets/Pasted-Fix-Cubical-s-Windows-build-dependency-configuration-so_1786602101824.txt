Fix Cubical's Windows build/dependency configuration so fresh clones/downloads can be built on Windows without manually installing missing native packages each time.

exifreader@4.42.0

@rollup/rollup-win32-x64-msvc@4.62.3
Lightning CSS fails because its Windows native binding is missing. We currently manually install:
lightningcss-win32-x64-msvc@1.32.0
Tailwind Oxide fails because its Windows native binding is missing. We currently manually install:
@tailwindcss/oxide-win32-x64-msvc

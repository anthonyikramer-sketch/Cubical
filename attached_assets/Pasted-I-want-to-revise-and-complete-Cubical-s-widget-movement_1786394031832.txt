==================================================
1. GLOBAL WIDGET MOVEMENT: REMOVE THE GRID
==================================================

Remove grid snapping entirely from ALL movable widgets.

There should no longer be a placement grid.

This applies anywhere widgets can be moved.

On Home:

- Widgets move completely freely.
- No grid increments.
- No predefined cells.
- No snapping to nearby widgets.
- No forced alignment.
- No forced rows or columns.

While dragging:

- The widget should follow the cursor continuously.
- Movement should feel smooth.
- Movement should feel ever so slightly soft/floaty rather than rigid.

However:

Do NOT add exaggerated inertia.
Do NOT make widgets slide after release.
Do NOT add bouncing.
Do NOT add overshoot.
Do NOT make precise placement difficult.

Think:

smooth
light
soft
responsive
precise

The widget should feel like a physical little object being moved around the workspace.

When I release the mouse:

The widget should stop where I released it.

If that position is valid, Cubical should not alter it.

==================================================
2. HOME IS A FREE-FLOATING DESKTOP
==================================================

Home should behave like a freeform desktop/workspace.

Every Home widget can be positioned wherever the user wants within the usable Home canvas.

Current examples include:

- Notepad

- Calendar
- Link Shelf
- Decision Maker
- Calculator

No grid.
No automatic arrangement.

3. KEEP WIDGETS ACCESSIBLE
==================================================

- bottom edge

Preserve the user's intended position as closely as possible.

4. SIDEBAR COLLISION BEHAVIOR
==================================================

The sidebar is NOT normal widget workspace.

A widget should not be allowed to remain hidden underneath the sidebar.

If I drag a widget partly over EMPTY sidebar space and release it:

- detect the overlap
- gently push/nudge the widget horizontally back into usable workspace
- preserve its vertical position as much as possible

Example:

Part of Notepad overlaps the sidebar.
My cursor is NOT over a valid navigation destination.
I release.

Result:

Notepad should gently move right just enough to become fully usable.

Do NOT:

- snap it to a grid
- return it to its previous position
- recenter it
- dramatically animate it

Just correct the invalid overlap.

## Tool Purpose

Clear Background is a lightweight image utility that allows the user to import an image and remove a white, near-white, or user-selected colored background by converting those pixels into transparency.

The primary workflow should be extremely simple:

**Open Clear Background → Add Image → Adjust if necessary → Export PNG**

This should feel like a small, focused Cubical utility rather than a full image editor.

## Core Functionality

### 1. Import Image

Allow the user to:

* Drag and drop an image into the tool.
* Click to browse for an image on their computer.

Support common image formats such as PNG, JPG/JPEG, and WebP where practical.

Once selected, display the image inside the tool.

### 2. Automatic White Background Removal

By default, Clear Background should target **white**.

Detect white and near-white pixels and convert them into transparent pixels.

The default settings should attempt to produce a useful result immediately so that, for a simple image on a white background, the user may only need to import the image and click Export.

### 3. Tolerance Control

Include a **Tolerance** slider.

This determines how similar a pixel must be to the target color before it is removed.

At low tolerance:

* Only pixels extremely close to the selected color should be affected.

At higher tolerance:

* A wider range of similar colors should become transparent.

The processed image preview must update in real time while the tolerance is adjusted.

Display the current tolerance value in a simple, understandable way.

### 4. Soft Edges / Anti-Aliasing

Avoid creating ugly white outlines around the remaining image.

Pixels around anti-aliased edges should be capable of becoming partially transparent based on their similarity to the target color.

The goal is to produce smooth edges instead of a harsh pixelated cutout.

Preserve the original colors of the subject as much as possible.

### 5. Select Another Background Color

Although the default target is white, allow the user to remove other solid-color backgrounds.

Include a **Pick Color** feature.

The user should be able to select a color from the imported image and make that the new target color.

Show a small color swatch indicating the currently selected target color.

The tolerance control should then operate relative to that selected color.

Include an easy way to return the target color to white.

### 6. Preview

Provide a clear preview of the processed image.

Use the standard checkerboard pattern behind transparent areas so transparency is immediately obvious.

The interface may show:

**Original | Result**

or another clean comparison layout if that works better with Cubical's existing design.

Do not let very large images break or overflow the interface. Scale them appropriately for preview while processing/exporting at their actual resolution.

### 7. Export

Include a prominent:

**Export PNG**

button.

PNG should be used because the exported file needs to preserve transparency.

The exported image should:

* Preserve transparency.
* Maintain the original image dimensions/resolution.
* Preserve the remaining image quality as much as possible.
* Save through a method compatible with both Cubical's current development environment and the packaged Electron desktop version.

### 8. Reset / New Image

Include controls to:

* Reset the current adjustments.
* Load a new image.

Reset should restore the default white target color and default tolerance without requiring the user to re-import the image.

## Privacy

Perform the actual image processing **locally on the user's computer**.

Do not upload images to an external service or API merely to remove the background.

This is intended to be a fast, offline-friendly Cubical utility.

--------------------------------------------------

3. Click anywhere on the PDF

8. Continue placing as many checkboxes as needed

Clicking the PDF should no longer place checkboxes.

Only one placement mode should be active at a time.

Checkbox active
→ click Stamp
→ Checkbox mode ends
→ Stamp mode begins

Stamp active
→ click Checkbox
→ Stamp mode ends
→ Checkbox mode begins

Checkbox active
→ click Select
→ Checkbox mode ends
